# 我的日常 · Mac 个人学习生活 App

原生 macOS 应用，包含首页、今日计划、开发工作、健身计划、饮食计划、游戏记录、笔记和本地数据管理。无需账号或网络，数据独立保存在本机。

当前为第一版候选实现。自动化与系统接口测试结果见 [验收报告](docs/ACCEPTANCE_REPORT.md)；真实电脑重启、休眠唤醒及系统通知点击仍需补充验收，未通过项明确保留。

## 环境

- Apple Silicon Mac；部署目标 macOS 14+，当前验证环境 macOS 15.6。
- 完整 Xcode 26.3 / Swift 6.2.4（当前构建环境）。未验证 Intel 构建。
- 无第三方包依赖，无云服务、遥测或外部字体。
- 本机旧 Command Line Tools 的 ManifestAPI 与链接库不一致，脚本默认选择已安装的完整 Xcode；通过 `DEVELOPER_DIR` 可指定兼容工具链，不修改系统默认设置。

## 构建和安装

在项目目录执行：

```bash
bash scripts/build-app.sh
```

输出 `dist/我的日常.app`。将它拖入 Mac 的“应用程序”文件夹即可使用，也可双击直接运行。应用运行后可在程序坞中选择“选项 → 在程序坞中保留”。不需要启动终端服务。

本地安装脚本：

```bash
bash scripts/install-app.sh
```

默认安装到当前用户的 `~/Applications/我的日常.app`。若已有同名应用，先退出，脚本会保留旧应用副本再更新。更新不会触碰数据文件。

应用使用 ad-hoc 本地签名，未进行 Developer ID 签名和公证；不承诺在其他电脑上直接通过 Gatekeeper。遇到安全警告应由用户确认来源并决定是否运行，不应关闭系统安全保护。

## 数据与备份

默认数据文件：

```text
~/Library/Application Support/PersonalLife/library.json
```

这是包含格式版本的 JSON 文件。应用通过安全替换保存，并使用独占锁阻止两个实例同时写入。请不要在应用运行时手动编辑该文件。

- 设置页可查看并打开真实数据位置。
- 每天首次成功保存后自动备份，保留最近 7 份每日备份。
- 可选择备份目录，或点击“立即备份”。默认位于数据目录下的 `Backups`。
- 手动备份及恢复前备份不会自动删除。
- 恢复时校验格式、版本、校验和和业务关联，确认后先备份当前数据，再整体替换。
- 损坏原文件会保留为 `.original` 副本；有效的恢复前数据另外生成 `.lifebackup`，可从应用恢复。
- 写入失败保留内存输入并提示重试，退出时不会静默丢弃未保存内容。
- 本地备份不防整台电脑损坏；可自行将备份文件复制到其他自有存储设备。

## 日常使用

- 今日计划：回车添加待办；详情设置日期、说明和提醒。旧未完成事项由你决定是否移到今天。
- 健身：设置单次或每周安排；实际组数、次数、重量与计划分开。今日计划引用同一训练记录。
- 开发：项目下分别管理任务、问题、笔记和进展，可归档和恢复。
- 饮食：计划与实际分开，可手填热量和蛋白质；空白不当作零。
- 游戏：输入名称和小时／分钟，记录同日多次游玩。
- 备忘与笔记：笔记自动保存，备忘点击“保存备忘”保存；备忘可转为待办或笔记，删除普通记录可撤销。

## 提醒边界

在设置页申请通知权限。系统拒绝时可打开系统通知设置启用。

- 已登记的通知交给 macOS；本机已验证登记、替换、取消和应用完全退出后的交付。
- 关闭窗口保留应用进程，程序坞可重新打开；`⌘Q` 完全退出。
- 专注模式、锁屏、休眠和关机可能影响横幅和交付时间。
- 每次启动及日期变化补充未来 45 天训练实例与提醒；长期不打开应用不会无限生成新通知。系统拒绝或容量不足会显示未登记状态。
- 错过的提醒在首页集中展示，点击“已知晓”后不重复显示同一时刻的提醒。
- 真实休眠、重启以及通知点击定位的完整人工验收尚待完成。

## 测试

全部可自动执行的测试：

```bash
bash scripts/test-all.sh
```

其中系统通知测试会发出一条测试通知，并要求此应用已获得通知权限。权限未开或未真实交付时测试失败，不跳过。

分项执行：

```bash
bash scripts/test.sh                    # 核心与应用模型 XCTest
bash scripts/test-data-processes.sh     # 三个独立进程：保存、重开、恢复
bash scripts/test-offline.sh            # 禁止网络的隔离进程执行相同数据流程
bash scripts/test-notifications.sh      # 真实系统登记、替换、取消、退出后交付
bash scripts/test-ui.sh                 # Xcode 页面点击、截图、保存及恢复
python3 scripts/check-repository.py     # 运行数据、凭据与被禁用测试检查
```

先构建应用，再运行依赖安装包的分项测试。所有测试使用虚构数据和独立临时目录，保留结果文件路径供核对。UI 测试使用独立应用标识与数据目录，临时选择系统英文输入源并在每个用例结束后恢复原输入源；包含中文长标题、窗口缩窄和程序坞重开。运行时会操作鼠标和键盘，请暂时不要同时操作测试窗口。测试截图和结果保存在 `.build/UIResults-*.xcresult`，不上传 GitHub。

真实重启的数据验证分两步执行，脚本不会自动重启电脑：

```bash
bash scripts/test-reboot.sh prepare
# 方便时由你重启 Mac，再执行：
bash scripts/test-reboot.sh verify
```

它在被 Git 忽略的 `data/reboot-check` 中保存虚构记录，比较系统启动时间，只有实际重启后才允许验证通过。此脚本只验证数据和备份恢复；重启后的通知交付仍需观察。
