## 实际发现并修复的问题

1. 默认 Command Line Tools 的 PackageDescription 接口与库不一致：改用已有完整 Xcode，不修改系统默认设置。
2. AppKit 入口主线程隔离错误：改用显式 MainActor 的应用入口。
3. 若干 SwiftUI 视图分组结构编译失败：修正代码后重跑原测试。
4. 后续训练修改在重开时补出错误历史：先冻结旧规则历史，再设置新规则生效日期；失败回归测试保留。
5. 备份时间依赖文件修改时间，可能把损坏文件当成功备份：改为实际校验备份并读取其创建时间；失败测试保留。
6. 早餐、午餐、加餐被误认为完整三餐：改为检查正餐餐次集合；失败测试保留。
7. 增加数据独占锁，阻止两个应用实例互相覆盖；附获取及释放测试。
8. 撤销已在内存完成但磁盘写入失败时，重复撤销入口未清理：现在消费已应用的撤销动作，保留恢复的记录和重试保存入口；失败回归测试保留。
9. 提醒点击定位提取为应用模型方法，测试日期、具体事项、完成/删除反馈及训练目标；失效目标清除旧焦点。
