# 页面与交互设计说明

依据 PRD；草图只指导结构，实际功能使用真实本地存储。导航固定为首页、今日计划、开发工作、健身计划、饮食计划、游戏娱乐、笔记、设置与数据。

| 页面 | 主要布局 | 编辑及反馈 |
| --- | --- | --- |
| 首页 | 今日事项、快速备忘、模块摘要 | 勾选任务，训练进入记录或直接完成；备忘转换后不重复生成 |
| 今日计划 | 日期选择、快捷添加、待处理／已完成／此前未完成 | 详情编辑名称、日期、说明、提醒；移到今天保留 ID，并同步调整提醒日期 |
| 开发工作 | 项目选择和项目详情，任务／问题／笔记／进展 | 项目归档可恢复；删除项目说明子内容影响；记录可编辑和删除 |
| 健身计划 | 日期、训练实例、安排列表 | 编辑安排区分这一次／后续；逐组实际数据即时保存；跳过与完成不同 |
| 饮食计划 | 日期、三餐、可选加餐、实际营养汇总 | 计划与实际分离；空营养不是零；复制计划后可修改 |
| 游戏娱乐 | 日期、记录列表、时长合计 | 小时分钟输入，近期游戏可选，支持编辑删除 |
| 笔记 | 标题正文搜索、笔记列表、编辑区 | 标题和正文自动保存，无结果显示空状态 |
| 设置与数据 | 数据位置、备份目录、备份恢复、通知权限 | 恢复前确认备份时间及全量覆盖；失败保留原数据 |

通用：保存失败不关闭编辑状态，显示重试；普通删除可撤销，包含多条内容的删除二次确认。窗口至少 880×620，内容可滚动；长文字不挤压操作按钮，系统字体适应外观。

训练后续修改：已完成、跳过、有实际记录或进入进行中的实例保留。未开始实例根据新安排更新，删除不再命中的未来未开始实例。单次修改保留 override 标记，后续模板刷新不覆盖该实例。

过去时间的提醒会进入错过提醒列表；完成或跳过条目不再提示。错过列表手动标记已知晓，以提醒标识和触发时间去重。修改时间后视为新的提醒。
